# yoko hanacoco 公式サイト

パール調ハンドメイドピアスの商品サイトです。`main` ブランチへの変更はGitHub ActionsによりGitHub Pagesへ自動公開されます。

## 主なファイル

- `index.html` — 商品ページ
- `legal/index.html` — 特定商取引法・個人情報の取扱い
- `assets/style.css` — デザイン
- `images/` — 商品画像
- `AGENTS.md` — Codexによる更新時の運営ルール

## 更新方法

Codexへ「価格を変更」「説明文を修正」「商品画像を差し替え」などと依頼してください。更新後に `main` へ反映すると自動公開されます。
